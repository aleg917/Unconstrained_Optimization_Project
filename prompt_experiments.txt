PREREQUISITE — Sparse Hessian support for P16

Before building the notebook, make two small changes to src/:

### A) `src/hessians/problem16.py` — return sparse diagonal

Modify `hess_f16(x)` to return a `scipy.sparse.diags` matrix (CSC format)
instead of `np.diag(diag_vals)`. This reduces memory from O(n^2) to O(n),
allowing Modified Newton to run on P16 even at n=100_000:

```python
import numpy as np
import scipy.sparse as sp

def hess_f16(x):
    x = np.asarray(x, dtype=float)
    n = len(x)
    j = np.arange(1, n + 1)
    diag_vals = j * np.cos(x) - 2.0 * np.sin(x)
    diag_vals[-1] = n * np.cos(x[-1]) + (n - 1) * np.sin(x[-1])
    return sp.diags(diag_vals, 0, format='csc')
```

### B) `src/methods/modified_newton.py` — sparse-aware Cholesky regularization

Add a sparse branch to `_modify_hessian_cholesky` that exploits diagonal
structure. For a diagonal matrix the Cholesky PD-check is simply
"all diagonal entries > 0", and the solve is element-wise division.
This keeps the Cholesky regularization algorithm (tau loop as PD oracle)
exactly as in the slides (Nocedal-Wright Alg. 6.3 / 3.3), while being
O(n) for diagonal inputs.

```python
import scipy.sparse as sp

def _modify_hessian_cholesky(H, beta=1e-3, max_iter=100):
    is_sparse = sp.issparse(H)

    if is_sparse:
        diag_H = np.asarray(H.diagonal(), dtype=float)
        diag_min = float(diag_H.min())
    else:
        diag_min = float(np.min(np.diag(H)))

    tau = 0.0 if diag_min > 0.0 else beta - diag_min
    n = H.shape[0]

    for j in range(max_iter):
        if is_sparse:
            # Cholesky for diagonal: PD iff all (d_i + tau) > 0
            diag_B = diag_H + tau
            if np.all(diag_B > 0):
                return diag_B, tau, j   # return the diagonal vector
            tau = max(2.0 * tau, beta)
        else:
            try:
                R = sla.cholesky(H + tau * np.eye(n), lower=False)
                return R, tau, j
            except sla.LinAlgError:
                tau = max(2.0 * tau, beta)

    raise RuntimeError(
        f"_modify_hessian_cholesky: no tau in {max_iter} iterations "
        f"makes H + tau*I positive definite (last tau={tau:.3e})."
    )
```

Then in the main `modified_newton` function, update the solve step:

```python
R_or_diag, tau, n_adj = _modify_hessian_cholesky(H, beta=beta,
                                                   max_iter=max_tau_iter)
n_chol_total += n_adj

if sp.issparse(H):
    # Diagonal: inverse is trivial, p = -g / diag(B_k)
    p = -g / R_or_diag
else:
    # Dense: standard Cholesky solve  R^T R p = -g
    p = sla.cho_solve((R_or_diag, False), -g)
```

Why this works: for a diagonal matrix D, Cholesky gives R = diag(sqrt(d_i)),
and R^T R p = -g solves to p = -g / d_i. The tau-adjustment loop is the
same algorithm as the slides, specialized for diagonal structure. Sparse
storage via scipy.sparse keeps memory O(n).

Make sure the rest of `modified_newton` (history recording, etc.) still
works — `tau` and `n_adj` are returned as before, only the type of the
first return value changes (dense R matrix vs. diagonal vector).

**Finite difference infrastructure** (`src.finite_diff_factories`):
- `make_fd_grad(f, k, scaled)` -> callable `g(x)` approximating grad f via
  forward FD. k: exponent (h=10^{-k}). scaled: if True, h_i = 10^{-k}*|x_i|
  (fallback to 10^{-k} if x_i=0).
- `make_fd_hess(grad_f, k, scaled, stencil)` -> callable `H(x)` approximating
  Hessian via FD of gradient (column-by-column, n+1 or 2n grad calls).

- `make_fd_hv(grad_f, k, scaled, stencil)` -> callable `hv(x, v)` for
  matrix-free Hessian-vector product via FD of gradient (1-2 grad calls per

**Efficient FD for P16** (`src.hessians.finite_diff`):
- `hess_fd_diag(grad_f, x, k, scaled, stencil)` — CPR with 1 color: extracts
  the entire diagonal Hessian with ONLY 2 gradient calls, regardless of n.
  Exploits the fact that P16's Hessian is diagonal (each g_j depends only
  on x_j). Returns a 1-D array (the diagonal).

**Stopping criteria** (`src.stopping_criteria`):
